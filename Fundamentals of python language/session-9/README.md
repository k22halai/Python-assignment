# Session 9: Python Lists & Built-in List Methods

This folder contains completed assignments for Session 9, demonstrating list creation, element addition (`append`, `insert`), item removal (`remove`, `pop`), and in-place sorting (`sort`, `reverse`).

## Tasks Overview

| Task # | File Name | Description | Key List Methods |
| :--- | :--- | :--- | :--- |
| **Task 1** | [`create_fav_apps_list.py`](./create_fav_apps_list.py) | Defines `my_fav_apps` with 5 daily apps and prints the list. | List declaration `[...]`, `len()` |
| **Task 2** | [`append_new_app.py`](./append_new_app.py) | Appends a newly started app to the end of the list. | `.append()` |
| **Task 3** | [`insert_whatsapp_app.py`](./insert_whatsapp_app.py) | Inserts `'WhatsApp'` at the second position (index 1) honoring 0-based indexing. | `.insert(1, ...)` |
| **Task 4** | [`remove_and_pop_apps.py`](./remove_and_pop_apps.py) | Removes an unused app by value with `.remove()` and deletes the last item with `.pop()`. | `.remove()`, `.pop()` |
| **Task 5** | [`sort_and_reverse_apps.py`](./sort_and_reverse_apps.py) | Alphabetizes and reverses the list strictly using list methods (no built-in `sorted()`). | `.sort()`, `.reverse()` |
