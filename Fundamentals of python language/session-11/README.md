# Session 11: Python Dictionaries — Key-Value Mapping & Operations

This folder contains completed assignments for Session 11, exploring dictionary creation, key insertion and value mutation, iteration via `.keys()`, `.values()`, `.items()`, custom formatting functions, and shopping cart dictionary management.

## Tasks Overview

| Task # | File Name | Description | Key Dictionary Concepts |
| :--- | :--- | :--- | :--- |
| **Task 1** | [`create_playlist_dict.py`](./create_playlist_dict.py) | Creates `my_playlist` with 3 songs as keys and durations in minutes as values. | Dictionary literal `{key: value}`, `len()`, `type()` |
| **Task 2** | [`add_and_update_playlist.py`](./add_and_update_playlist.py) | Adds a new song and updates the duration of an existing song in `my_playlist`. | Key assignment `dict[key] = value`, mutation |
| **Task 3** | [`display_instagram_friends.py`](./display_instagram_friends.py) | Defines `display_friends()` to format username/followers as `'username: 2.3K followers'`. | Dict traversal, string formatting, function design |
| **Task 4** | [`food_order_dict_methods.py`](./food_order_dict_methods.py) | Uses `.keys()`, `.values()`, and `.items()` on `food_order = {'Pizza': 2, 'Burger': 1, 'Fries': 3}`. | `.keys()`, `.values()`, `.items()` dictionary views |
| **Task 5** | [`flipkart_cart_updater.py`](./flipkart_cart_updater.py) | Defines `update_cart(cart, item, qty)` to insert or update item quantities in a shopping cart. | Conditional dictionary updating, in-place dict modification |
