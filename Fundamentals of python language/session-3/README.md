# Session 3: User Input, Output Formatting & Typecasting

This folder contains completed assignments for Session 3, covering `input()`, `print()`, typecasting (`int()`, `float()`), escape characters (`\n`, `\t`), and operator conditionals.

## Tasks Overview

| Task # | File Name | Description | Key Concepts |
| :--- | :--- | :--- | :--- |
| **Task 1** | [`welcome_food_input.py`](./welcome_food_input.py) | Prompts user for name and favorite food, then prints a personalized welcome message. | `input()`, `print()`, string interpolation |
| **Task 2** | [`arithmetic_operations.py`](./arithmetic_operations.py) | Takes two numbers, converts to `int`, and outputs sum, difference, product, and quotient. | `int()` typecasting, arithmetic operators |
| **Task 3** | [`zomato_bill_calculator.py`](./zomato_bill_calculator.py) | Calculates total food bill using `float(price)` and `int(quantity)`. | `float()` & `int()` typecasting, currency formatting |
| **Task 4** | [`instagram_follower_count.py`](./instagram_follower_count.py) | Formats Instagram follower count with thousands separator and `\n` & `\t` escape characters. | Escape sequences (`\n`, `\t`), numeric formatting |
| **Task 5** | [`basic_calculator.py`](./basic_calculator.py) | Interactive calculator executing `+`, `-`, `*`, `/` with operator validation and zero-division protection. | Control flow (`if/elif/else`), typecasting, error handling |
