# Session 7: Loop Control Statements — `continue`, `break`, and `pass`

This folder contains completed assignments for Session 7, demonstrating loop alteration techniques in Python.

## Tasks Overview

| Task # | File Name | Description | Key Control Statement |
| :--- | :--- | :--- | :--- |
| **Task 1** | [`skip_banana_continue.py`](./skip_banana_continue.py) | Iterates over `['Apple', 'Banana', 'Mango', 'Orange']` and skips `'Banana'`. | `continue` (skips remaining code in current iteration) |
| **Task 2** | [`search_burger_king_break.py`](./search_burger_king_break.py) | Searches list of food items and terminates loop immediately upon finding `'Burger King'`. | `break` (immediately exits the loop) |
| **Task 3** | [`skip_focus_pass.py`](./skip_focus_pass.py) | Checks playlist names and executes `pass` when encountering `'Focus'`, printing all other playlists. | `pass` (syntactical no-op placeholder) |
| **Task 4** | [`filter_spam_break_continue.py`](./filter_spam_break_continue.py) | Combines `continue` to skip `'Spam'` messages and `break` to stop upon finding `'How are you?'`. | Combined `continue` + `break` in a single loop |
