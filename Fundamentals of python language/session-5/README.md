# Session 5: Loops — The `for` Loop

This folder contains completed assignments for Session 5, focusing on iteration using `for` loops across lists, strings, and filtered character extraction.

## Tasks Overview

| Task # | File Name | Description | Key Concepts & Constraints |
| :--- | :--- | :--- | :--- |
| **Task 1** | [`food_delivery_apps.py`](./food_delivery_apps.py) | Iterates through a list of 5 popular food delivery apps and prints each on a new line. | `for` loop over lists, sequential printing |
| **Task 2** | [`count_bio_characters.py`](./count_bio_characters.py) | Counts characters in `user_bio = 'Music lover \| Foodie \| Traveller'` excluding whitespace. | String iteration, counter variable, `if char != ' '` |
| **Task 3** | [`favorite_movies_uppercase.py`](./favorite_movies_uppercase.py) | Loops over a list of 3 favorite movies and prints them in capital letters. | List traversal, string transformation with `.upper()` |
| **Task 4** | [`extract_vowels.py`](./extract_vowels.py) | Extracts vowels from user-entered song/word. Strictly adheres to constraint avoiding `'in'`. | `for` loop over string, character filtering using multiple `==` comparisons |
