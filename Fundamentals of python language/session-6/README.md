# Session 6: Loops — The `while` Loop & Nested Loops

This folder contains completed assignments for Session 6, demonstrating conditional iteration, decrement countdowns, infinite loop control using `break`, and 2D pattern generation using nested `while` loops.

## Tasks Overview

| Task # | File Name | Description | Key Concepts |
| :--- | :--- | :--- | :--- |
| **Task 1** | [`print_numbers_while.py`](./print_numbers_while.py) | Prints numbers 1 through 10 sequentially using a `while` loop. | Loop initialization, termination condition (`<= 10`), counter increment |
| **Task 2** | [`zomato_offer_countdown.py`](./zomato_offer_countdown.py) | Counts down an offer duration from 5 minutes down to 0. | Decrementing while loop (`-= 1`), boundary conditions |
| **Task 3** | [`right_triangle_pattern.py`](./right_triangle_pattern.py) | Generates a 5-row right-angled triangle star pattern (`*`). | Nested `while` loops, row/column index management |
| **Task 4** | [`loading_spinner_simulation.py`](./loading_spinner_simulation.py) | Simulates an infinite spinner with `while True` and terminates after 3 iterations via `break`. | Infinite loops (`while True`), loop exit via `break` |
| **Task 5** | [`pyramid_star_pattern.py`](./pyramid_star_pattern.py) | Produces a centered 4-row pyramid (`*`, `***`, `*****`, `*******`) using two nested while loops. | Multi-nested while loops (one for spaces, one for stars) |
