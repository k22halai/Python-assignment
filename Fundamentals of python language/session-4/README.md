# Session 4: Control Flow — Conditional Statements

This folder contains completed assignments for Session 4, demonstrating decision-making in Python using `if`, `elif`, `else`, and nested conditions.

## Tasks Overview

| Task # | File Name | Description | Key Concepts |
| :--- | :--- | :--- | :--- |
| **Task 1** | [`instagram_eligibility.py`](./instagram_eligibility.py) | Checks if user is at least 13 years old to open an Instagram account. | `if-else`, relational operators (`>=`) |
| **Task 2** | [`student_grade_calculator.py`](./student_grade_calculator.py) | Maps marks (0-100) to letter grades (A, B, C, D, F) with range validation. | `if-elif-else` ladder, multi-condition branching |
| **Task 3** | [`zomato_late_night_order.py`](./zomato_late_night_order.py) | Verifies age (18+) and late-night order hours (22:00 to 02:00) using nested conditions. | Nested `if` statements, logical `or` across midnight |
| **Task 4** | [`cricket_score_evaluator.py`](./cricket_score_evaluator.py) | Evaluates cricket scores (High Score, Good Score, Average, Needs Improvement). | `if-elif-else` condition ranges |
