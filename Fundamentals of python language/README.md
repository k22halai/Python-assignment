# Fundamentals of Python Language 🐍

A structured repository containing assignments, practical implementations, and real-world exercises covering the core fundamentals of Python programming (Sessions 1 through 12).

---

## 📑 Repository Structure & Curriculum

| Session | Topic / Module | Description & Key Concepts | Folder |
| :--- | :--- | :--- | :--- |
| **Session 1** | **Introduction & Architecture** | Execution flows, compiled vs. interpreted languages (Python, C, Java), real-world tech stack use cases (Instagram, Spotify, Uber). | [`session-1/`](./session-1/) |
| **Session 2** | **Variables & Memory Management** | Variable declarations, PEP 8 snake_case naming, primitive vs. non-primitive types, memory addresses (`id()`). | [`session-2/`](./session-2/) |
| **Session 3** | **Operators & User Input** | Arithmetic operations, type casting, interactive CLI user input (`input()`), bill calculation logic. | [`session-3/`](./session-3/) |
| **Session 4** | **Conditional Statements** | `if`, `elif`, `else` decision structures, logical operators (`and`, `or`, `not`), eligibility and evaluation scripts. | [`session-4/`](./session-4/) |
| **Session 5** | **For Loops & Iterables** | Iterating through collections, string traversal, vowel extraction, character counting, and case transformations. | [`session-5/`](./session-5/) |
| **Session 6** | **While Loops & Patterns** | `while` loop conditions, countdown simulation, interactive loading spinners, star pattern rendering (pyramids, right triangles). | [`session-6/`](./session-6/) |
| **Session 7** | **Loop Control Statements** | `break`, `continue`, and `pass` mechanisms, search algorithms with early exit, content filters. | [`session-7/`](./session-7/) |
| **Session 8** | **String Manipulation** | String slicing, string methods (`split`, `join`, `replace`, `upper`), data masking (phone numbers), reversing messages. | [`session-8/`](./session-8/) |
| **Session 9** | **Python Lists** | List creation, indexing, mutating operations (`append`, `insert`, `remove`, `pop`), sorting, and reversing. | [`session-9/`](./session-9/) |
| **Session 10** | **Python Tuples** | Tuple creation, indexing, slicing, tuple concatenation, demonstrating tuple immutability vs. lists. | [`session-10/`](./session-10/) |
| **Session 11** | **Python Dictionaries** | Key-value pairs, nested dictionaries, dictionary methods (`keys()`, `values()`, `items()`, `update()`, `get()`). | [`session-11/`](./session-11/) |
| **Session 12** | **Functions & Functional Tools** | Custom functions, parameter handling, return values, higher-order functions (`map`, `filter`, `reduce`), lambda expressions. | [`session-12/`](./session-12/) |

## 🚀 How to Run Any Script

1. **Clone the repository:**
   ```bash
   git clone https://github.com/k22halai/fundamental-of-python-language.git
   cd fundamental-of-python-language
   ```

2. **Run any session file directly with Python 3:**
   ```bash
   python session-1/hello_instagram.py
   python session-3/basic_calculator.py
   python session-12/calculate_discounted_price.py
   ```

## 📌 Prerequisites
- Python 3.8 or higher installed on your system.
