# Session 12: Functions & Functional Programming (`lambda`, `map`, `filter`, `reduce`)

This folder contains completed assignments for Session 12, covering Python functions, parameterized calculations, numeric string abbreviation, and functional programming paradigms using `lambda` functions with `map()`, `filter()`, and `reduce()`.

## Tasks Overview

| Task # | File Name | Description | Key Functional Concepts |
| :--- | :--- | :--- | :--- |
| **Task 1** | [`calculate_discounted_price.py`](./calculate_discounted_price.py) | Calculates discounted price from `price` and `discount_percent`. Tested with 500 and 10%. | User-defined functions `def`, arithmetic return |
| **Task 2** | [`format_follower_count.py`](./format_follower_count.py) | Formats numeric counts to Instagram-style (`1500` $\rightarrow$ `'1.5K'`, `1200000` $\rightarrow$ `'1.2M'`). | Range conditionals, string formatting |
| **Task 3** | [`map_durations_to_seconds.py`](./map_durations_to_seconds.py) | Transforms a list of song durations in minutes to seconds using `map()` and `lambda`. | `map()`, `lambda`, list transformation |
| **Task 4** | [`filter_products_starting_with_m.py`](./filter_products_starting_with_m.py) | Filters a product catalog for items starting with `'M'` using `filter()` and `lambda`. | `filter()`, `lambda`, boolean predicate |
| **Task 5** | [`reduce_swiggy_total_bill.py`](./reduce_swiggy_total_bill.py) | Accumulates total Swiggy bill amount using `reduce()` from `functools` and `lambda`. | `functools.reduce()`, `lambda`, sequence reduction |
